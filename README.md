
# 🍕 Pizza Sales Analysis

This project analyzes pizza sales data to identify sales trends, popular items, and revenue drivers.

## 📂 Tools & Setup
- SQL

## 📄 Dataset
- Orders
- Pizza types
- Categories
- Revenue

## 🎯 Business Questions
- Which pizza sells the most?
- Best sales day and time?
- Revenue by category?

## 💡 Key Insights
- Classic pizzas generate highest revenue
- Weekends have peak sales

## 📁 Files Included
- Pizza Sales SQL file
- Dataset

## 🛠 How to Run
Execute SQL queries and visualize results
